Ashcombe University Network

Education April 22, 2021

Standardized reporting across campuses

A Fragmented Network

Ashcombe University Network needed a way to standardize reporting across its member campuses. Each institution tracked facilities data differently, using tools ranging from homegrown databases to paper binders archived in basement storage rooms.

Shared Templates, Local Ownership

Ordinant Carbon Solutions gave the network a common reporting framework while preserving campus-level autonomy:

  • Each campus submits data through consistent templates
  • Network administrators review submissions before consolidation
  • Leadership sees completion status across all member institutions

“We didn’t want to impose one campus’s process on everyone else. We wanted a shared language.” — Fenella Okoro

Implementation Steps

  1. Identify data sources and reporting owners at each member campus
  2. Configure network-wide templates aligned to disclosure requirements
  3. Establish a quarterly review cadence with network-level sign-off

Each campus now submits data through a shared system with consistent templates, giving Ashcombe standardized reporting across campuses for the first time.
